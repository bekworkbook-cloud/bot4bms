# Telegram-бот «Склад»

Бот для учёта товаров на складе: приход, списание, остатки, поиск, удаление и история операций.
Стек: Python 3.10+, aiogram 3, SQLite (aiosqlite).

## Функции

| Кнопка / команда | Что делает |
|---|---|
| **Добавить товар** (`/add`) | Спрашивает название и количество. Если товар уже есть, количество прибавляется, дубль не создаётся. Названия сравниваются без учёта регистра и лишних пробелов. |
| **Списать товар** (`/remove`) | Выбор товара кнопкой и ввод количества. Списать больше, чем есть, нельзя. При остатке 0 товар остаётся в списке. |
| **Остатки** (`/list`) | Весь список по алфавиту с итогами. Длинный список делится на несколько сообщений. |
| **Найти товар** (`/find <запрос>`) | Поиск по части названия без учёта регистра. |
| **Удалить товар** (`/delete`) | Выбор товара и подтверждение «Да, удалить» / «Отмена». |
| **История операций** (`/history`) | Последние 20 операций: кто, что, на сколько, когда. |
| `/cancel` | Прерывает текущий диалог в любой момент. |

Ограничения ввода: название от 2 до 100 символов, количество — целое число от 1 до 1 000 000.
При неверном вводе бот объясняет причину и повторяет тот же вопрос.
Если посреди диалога нажать другую кнопку меню, текущий диалог отменится и начнётся новый.

Доступ есть только у пользователей из `ALLOWED_USERS`. Остальным бот отвечает «У вас нет доступа».

## Установка и запуск

1. Установите Python 3.10 или новее.

2. Создайте виртуальное окружение и установите зависимости:

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate          # Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.

4. Узнайте свой Telegram ID, например у [@userinfobot](https://t.me/userinfobot).

5. Скопируйте `.env.example` в `.env` и заполните его:

   ```bash
   cp .env.example .env
   ```

   ```ini
   BOT_TOKEN=123456789:AAAA-ваш-токен
   ALLOWED_USERS=123456,789012
   # необязательно:
   # DB_PATH=data/sklad.db
   # TIMEZONE=Asia/Tashkent
   ```

   | Переменная | Обязательна | Описание |
   |---|---|---|
   | `BOT_TOKEN` | да | Токен бота от @BotFather |
   | `ALLOWED_USERS` | да | Telegram ID через запятую |
   | `DB_PATH` | нет | Путь к файлу базы, по умолчанию `data/sklad.db` |
   | `TIMEZONE` | нет | Часовой пояс для дат в истории (IANA, например `Europe/Moscow`), по умолчанию время сервера |

6. Запустите бота:

   ```bash
   python main.py
   ```

   Откройте бота в Telegram и отправьте `/start`.

Файл `.env` и база данных не попадают в репозиторий (см. `.gitignore`).
Данные хранятся в SQLite-файле и сохраняются после перезапуска.

## Структура проекта

```
main.py          — точка входа, сборка диспетчера, запуск polling
config.py        — чтение настроек из .env
database.py      — SQLite: таблицы products и operations, транзакции
keyboards.py     — главное меню и инлайн-кнопки (выбор товара, подтверждение)
middlewares.py   — проверка доступа по ALLOWED_USERS
handlers/
  __init__.py    — порядок подключения роутеров
  states.py      — состояния диалогов (FSM)
  common.py      — /start, /cancel, нетекстовые сообщения, обработка ошибок
  add.py         — добавление товара
  remove.py      — списание
  stock.py       — остатки
  search.py      — поиск
  delete.py      — удаление
  history.py     — история операций
  utils.py       — проверка ввода, форматирование, разбиение длинных сообщений
```

## База данных

**products**: `id`, `name` (нормализованное название, unique), `display_name` (как ввёл пользователь),
`quantity` (≥ 0), `updated_at`.

**operations**: `id`, `product_name`, `user_id`, `user_name`, `delta` (+20 / −3; при удалении — минус остаток),
`action` (`add` / `remove` / `delete`), `created_at`.

Время хранится в UTC (ISO 8601) и переводится в `TIMEZONE` при выводе.
Остаток меняется в транзакции (`BEGIN IMMEDIATE`), а списание выполняется одним условным `UPDATE ... WHERE quantity >= ?`,
поэтому при одновременной работе нескольких пользователей остаток не уйдёт в минус и данные не потеряются.
